# Script — Why Old Hardware Still Matters

**Target runtime:** 45–55 seconds

## Narration / on-screen copy

**0–4s — Hook**
What if an old computer had one advantage a new server couldn't fake?

**4–12s**
RustChain uses a model called Proof of Antiquity. The basic idea is simple: one physical CPU gets one baseline vote.

**12–22s**
But reward weight can change with hardware antiquity, so genuinely older machines can matter instead of being treated as e-waste.

**22–35s**
The hard part is proving the machine is real. RustChain uses hardware attestation and fingerprinting checks to make cheap VM copies less useful than physical hardware.

**35–46s**
So the scarce resource isn't just electricity, capital, or cloud scale. It's verified physical hardware with history.

**46–53s — CTA**
Want to see the protocol? Start with the RustChain repo and `pip install clawrtc`.

- Digital Index Base = non-B2B main brand.
- Digital Index Base @stratum = B2B lane.

- Language is not a routing rule. Japanese and English can coexist under the same brand.

## Migration rule

Do not delete useful legacy assets merely because their URL or original branding is old. Prefer:

1. expose the asset from the correct current brand,
2. update brand ownership and routing,
3. copy/rebuild only when it improves clarity, SEO, measurement or maintenance,
4. keep legacy sites as subordinate properties when they still have value.

# Publishing Demand Intake

Use this intake when Publishing Revenue Cell finds a topic with real external demand but insufficient implementation evidence.

Required fields:

- Market signal / source
- Audience / buyer
- Pain or curiosity
- Why this matters now
- Existing Capability Lab evidence already checked
- Repo / Skill / Pattern to test
- Minimum real execution test
- Success condition
- Failure condition
- Revenue relevance
- Priority

Do not create a research request only because a topic looks publishable. External demand evidence or repeated reader/buyer pain should exist first.
